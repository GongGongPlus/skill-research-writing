# 统计检验与实验设计

**第一步该做什么**：拿到数据先回答三件事——数据类型（连续/分类/序数）、是否配对、是否正态，然后查决策树。

## 检验选择决策树（已确认）

| 场景 | 检验 |
|---|---|
| 两独立组 + 正态 | 独立样本 t 检验（方差不齐用 Welch） |
| 两独立组 + 非正态 | Mann-Whitney U |
| 配对 + 正态 | 配对 t 检验 |
| 配对 + 非正态 | Wilcoxon 符号秩 |
| 3+ 组 + 正态 | ANOVA（方差不齐用 Welch ANOVA / Brown-Forsythe） |
| 3+ 组 + 非正态 | Kruskal-Wallis |
| 期望频数 <5（2×2） | Fisher 精确检验 |
| 分类关联 | 卡方（期望频数不足改 Fisher） |

- 正态性：n≥100 时 Q-Q 图权重高于 Shapiro-Wilk p 值；每组 n>30 的轻微违反可继续参数检验。
- 回归方差不齐 → 稳健标准误 HC3。

## 效应量基准（约定非定律）

Cohen's d：0.2 / 0.5 / 0.8；η²_p：0.01 / 0.06 / 0.14；r：0.1 / 0.3 / 0.5；Cramér's V：0.07 / 0.21 / 0.35。

## APA 报告五要素（缺一不可）

1. 描述统计（M±SD）。
2. 精确 p 值：p=.034，不写 p<.05；仅 <.001 才写 p<.001。
3. 带 CI 的效应量。
4. 假设检查结果。
5. 全部计划分析（含不显著的）。

## 功效分析与样本量

- A priori 功效分析：α=0.05、power=0.80 起步；事后 observed power 是循环论证，改做敏感性分析。
- `solve_power` 对 ANOVA 返回总 N 而非每组 n——除以组数。
- 聚类设计：方差乘设计效应 `1+(m−1)×ICC`。
- 按预期脱落率放大 n。

## 实验设计红线

- **伪重复判定**：重复单元 = 随机化单元。处理作用于小鼠则 n=3（鼠）而非 n=300（细胞）。
- 运行顺序随机化（防时间漂移）；培养板边缘效应随机/区组化，勿把对照全放第 1 列。

## 多重比较

计划外检验换到显著 = 作废 p 值；多重比较须校正并写明方法（Bonferroni/FDR）。

## 如何证明统计结论站得住

① 检验选择能通过决策树复现（三前提：类型/配对/正态有据）；② 效应量与 CI 齐备，p 值精确；③ 数据可得时重跑一遍结果一致。审稿人质疑时，先答决策树三前提，再给效应量——先辩 p 值 = 下策。

## P 值报告铁律（ima 实战文章「P值不可以单独出现」蒸馏 + 全网对标）

- **p 值永远不单独出现**：报告 p 值时 MUST 同时给两组的具体数值（均值±SD/CI），否则读者无法判断差异是否有实际意义——"3.0 vs 2.6，p<0.05"并不说明后者更好。
- **单/双尾声明**：报告 p 值时 MUST 声明单尾还是双尾；原文未声明时禁止默认双尾，标注"未披露，按保守处理"。
- **可重算性**：每个统计结论 MUST 由 样本量 + 检验统计量 + 自由度 可重算出 p 值；重算不符即判 MISCOMPUTED，优先于"字段缺失"。
- **报告规范**：若研究类型为随机试验/观察研究/系统综述，MUST 对照 CONSORT/STROBE/PRISMA 逐项自检，缺项在投稿前列出。
- 摘要里出现"显著提升/显著降低"而无效应量与数字 → MUST 补上数字或改为定量表述。
